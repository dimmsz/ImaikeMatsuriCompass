# ImaikeMatsuriCompass

2026年の今池まつりを会場から探せる非公式Webアプリです。

## 現在の機能

- 公式タイムテーブルに掲載されている10会場を一覧表示
- 会場をマップ上のピンとして表示
- 会場名・目印で検索
- 会場詳細からGoogle Mapsを開く
- PWA manifest対応
- ブラウザの現在地ボタンからGoogle Mapsを開く

## 対応イベント

2026年9月20日(日)・21日(月・祝)の今池まつりを対象としています。
